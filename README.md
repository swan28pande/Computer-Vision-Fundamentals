# Computer Vision Fundamentals

A comprehensive collection of computer vision algorithms and techniques with practical implementations and visual demonstrations.

## Current Projects

### 1. Edge Detection
**Location**: `Edge Detection/`

Advanced edge detection and image processing:
- Canny Edge Detection
- Sobel Operators  
- Color Channel Analysis
- Histogram Analysis
- Multi-level Edge Detection

### 2. 3D Rendering & Stereo Vision
**Location**: `Translation+Rotation+Stereo_camera/`

3D computer vision techniques:
- Real-time 3D cube rendering
- Camera projection and texture mapping
- Stereo vision simulation
- Physics-based animation

## Technologies

- Python 3.8+
- OpenCV (cv2)
- NumPy
- Jupyter Notebook
- Matplotlib

## Quick Start

```bash
# Install dependencies
pip install opencv-python numpy matplotlib jupyter

# Run Edge Detection
jupyter notebook Edge\ Detection/code.ipynb

# Run 3D Rendering
python Translation+Rotation+Stereo_camera/code.py
```
